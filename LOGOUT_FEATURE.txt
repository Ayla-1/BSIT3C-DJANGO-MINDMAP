LOGOUT BUTTON FEATURE
====================================================================

✓ LOGOUT FUNCTIONALITY HAS BEEN ADDED!

There are now TWO ways to logout from the MindMap system:

====================================================================
1. TOP NAVIGATION BAR (Dropdown Menu)
====================================================================
Location: Top-right corner of every page when logged in
How to use:
  1. Click on your name in the top-right corner
  2. A dropdown menu will appear
  3. Click "Logout"

Available on:
  ✓ Admin Dashboard
  ✓ Teacher Dashboard
  ✓ Student Dashboard
  ✓ All other authenticated pages

====================================================================
2. SIDEBAR LOGOUT BUTTON (Direct Link)
====================================================================
Location: At the bottom of the left sidebar
Appearance: Red "🚪 Logout" button with separator line above it

Available on:
  ✓ Admin Dashboard & all admin pages
  ✓ Teacher Dashboard & all teacher pages
  ✓ Student Dashboard & all student pages

Visual Design:
  - Red text color (#dc3545)
  - Bold font weight
  - Hover effect: Changes to red background with white text
  - Separated from other menu items with a horizontal line

====================================================================
LOGOUT URL
====================================================================
Direct logout URL: http://localhost:8000/logout/

What happens when you logout:
  1. Your session is terminated
  2. You are redirected to the login page
  3. You need to login again to access the system
