2. FILTER STUDENTS BY SECTION
====================================================================

Filter Options:
  📚 Course: Filter by BSIT, BSCS, BSIS, etc.
  📅 Year Level: Filter by 1st, 2nd, 3rd, 4th year
  📋 Section: Filter by A, B, C, etc.

How to Use:
  1. Select a filter from any dropdown
  2. Results update automatically
  3. Combine multiple filters for specific results
  4. Click "Clear Filters" to reset

Examples:
  - Show only BSIT students: Select "BSIT" from Course
  - Show 3rd year Section C: Select Year "3" and Section "C"
  - Show all 1st year students: Select Year "1"

3. ADD STUDENT FEATURE
====================================================================

How to Add a Student:
  1. Click the "➕ Add Student" button (top-right of Student Management card)
  2. Fill in the form:
     
     Required Fields (marked with *):
     - Student Number (unique, e.g., 2024-0001)
     - First Name
     - Last Name
     - Course (e.g., BSIT)
     - Year Level (1-4)
     - Section (e.g., A, B, C)
     
     Optional Fields:
     - Email
     - Gender (Male/Female)
     - Birthdate
     - Enrollment Date (defaults to today)
  
  3. Click "Add Student"
  
  4. System automatically:
     - Adds student to database
     - Creates user account
     - Sets username = student number
     - Sets default password = "student123"
     - Creates student role profile

Success Message:
  "Student [Name] added successfully! Login credentials: [number]/student123"
