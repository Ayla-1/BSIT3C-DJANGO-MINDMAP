================================================================================
    MINDMAP - QUICK START GUIDE
    Student Academic Progress Monitoring System
================================================================================

STEP 1: START MYSQL
-------------------
1. Open XAMPP Control Panel
2. Click "Start" next to MySQL
3. Wait for green indicator

STEP 2: IMPORT DATABASE
-----------------------
1. Visit: http://localhost/phpmyadmin
2. Create database: mindmap_db
3. Click "Import" tab
4. Choose: SQL/mindmap_db.sql
5. Click "Go"

STEP 3: INSTALL DEPENDENCIES
-----------------------------
Open PowerShell in project folder and run:

    pip install -r requirements.txt

STEP 4: TEST DATABASE CONNECTION
---------------------------------
    python test_connection.py

You should see: "✓ Database connection successful!"

STEP 5: RUN MIGRATIONS
-----------------------
    python manage.py migrate

STEP 6: CREATE USER ACCOUNTS
-----------------------------
    python setup_database.py

This creates:
- Admin user (admin / admin123)
- Teacher users (email prefix / teacher123)
- Student users (student number / student123)

STEP 7: START SERVER
--------------------
Option A: Double-click "start_server.bat"
Option B: Run in terminal:
    
    python manage.py runserver

STEP 8: ACCESS APPLICATION
---------------------------
Open browser and visit:

    http://127.0.0.1:8000/

Login with:
    Username: admin
    Password: admin123

    python setup_database.py

================================================================================
TROUBLESHOOTING
================================================================================

Can't connect to database:
  → Start MySQL in XAMPP
  → Check database name is "mindmap_db"

Module not found:
  → pip install -r requirements.txt

Profile not found error:
  → python setup_database.py

Port already in use:
  → python manage.py runserver 8080
